Inga I + II · du fleuve au réseau

Guide de diffusion

Ce dossier contient toute la simulation : page, moteur 3D, polices, voix de narration. Il fonctionne sans Internet, sur ordinateur, tablette et téléphone, dans tout navigateur récent avec WebGL.

ContenuRôle
index.htmlVersion normale : intro, simulation, visite guidée.
musee.htmlVersion borne : démarre seule, boucle la visite quand personne ne touche l’écran, se réinitialise après le départ d’un visiteur.
Lancer_musee.batWindows : ouvre musee.html en plein écran, son automatique, hors ligne. Quitter : Alt + F4.
Ouvrir_Inga.batWindows : ouvre la simulation dans une fenêtre d’application normale.
voix/Narration Perle (ElevenLabs), une piste par étape.

1. Partager un lien (le plus simple)

Mettez le dossier en ligne sur un hébergement statique gratuit. Vous obtenez une adresse à envoyer ou à mettre en QR code.

  1. Netlify Drop : ouvrez app.netlify.com/drop et glissez le dossier Inga_I_II. L’adresse est prête en une minute.
  2. Autres options équivalentes : Cloudflare Pages, GitHub Pages.
  3. Partagez …/index.html pour le public, …/musee.html pour une borne.
Une fois en ligne, la simulation s’installe comme une application : sur téléphone, menu du navigateur puis « Ajouter à l’écran d’accueil » ; sur ordinateur, l’icône « Installer » de la barre d’adresse. Après la première visite, elle fonctionne hors ligne.

2. Écran de musée (recommandé : mini-PC Windows + écran tactile)

  1. Copiez le dossier sur le mini-PC (par exemple C:\Inga_I_II).
  2. Double-cliquez Lancer_musee.bat. Chrome ou Edge s’ouvre en plein écran, sans barre ni menu.
  3. Démarrage automatique : touches Win + R, tapez shell:startup, puis placez-y un raccourci vers Lancer_musee.bat.
  4. Paramètres Windows : désactivez la mise en veille de l’écran et de l’ordinateur, et les mises à jour pendant les heures d’ouverture.
  5. Option pour les sites exposés au public : « Accès attribué » (mode kiosque de Windows) pour verrouiller le poste.

Comportement en mode musée : la page entre seule dans le site 3D, lance la visite commentée après 60 secondes sans contact, la rejoue en boucle, et revient à l’état initial quand un visiteur s’en va. Les liens externes et le clic droit sont désactivés.

Matériel conseillé : processeur graphique récent (Intel Iris Xe, AMD Radeon intégré ou mieux), écran 1080p tactile, haut-parleurs ou casque. Un Raspberry Pi est trop faible pour ce rendu 3D.

3. Tablette en borne

  • Android : application « Fully Kiosk Browser », adresse …/musee.html (version en ligne), avec la lecture automatique des médias autorisée.
  • iPad : ouvrez l’adresse dans Safari, « Sur l’écran d’accueil », puis « Accès guidé » (Réglages, Accessibilité). Apple exige un premier toucher avant le son : un bouton « Écouter cette étape » apparaît alors dans la visite.

4. Son et navigateurs

Le premier toucher (bouton « Visite guidée ») débloque le son pour toute la visite. Si un navigateur bloque quand même l’audio, la visite affiche un bouton « Écouter cette étape ». En mode borne lancé par Lancer_musee.bat, le son démarre sans toucher.

5. Mise à jour

Remplacez le dossier par la nouvelle version, ou glissez-le de nouveau sur Netlify. Les appareils qui ont installé l’application récupèrent la mise à jour à la visite suivante.

Simulation éducative et reconstruction partielle : aucune télémétrie SNEL. Relief : Copernicus GLO-30. Sources détaillées dans le Registre de l’application.
